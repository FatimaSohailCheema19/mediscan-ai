# Med AI - AI Powered Medical Diagnosis Web Application

## Overview
Med AI is an AI-powered medical diagnosis web application developed using React and custom-trained deep learning models.

The system analyzes medical scan images and predicts whether the patient is healthy or shows signs of disease. It supports multiple scan categories including brain, lung, and breast scans.

The application also generates AI-based medical-style reports using LLM integration.

---

## Features

- Brain scan analysis
- Lung scan analysis
- Breast scan analysis
- AI-powered disease prediction
- Confidence score generation
- Automated medical report generation
- Interactive React frontend
- Custom-trained AI model integration
